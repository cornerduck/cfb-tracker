# STRDYS screens

Each file is one screen. Files starting with **M** are the mobile version (390 px wide); the others are desktop (1440 × 900).
Template syntax: `{{ value }}` = data, `<sc-for>` = repeated item, `<sc-if>` = shown conditionally. All data is sample or placeholder data.
